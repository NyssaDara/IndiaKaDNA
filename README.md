# 🇮🇳 IndiaKaDNA

### Every place has a past. Every story has a place.

IndiaKaDNA is a digital heritage archive dedicated to discovering, documenting and preserving India's rich cultural history.

## ✨ About the Project

IndiaKaDNA aims to bring India's monuments, architecture, traditions, photographs and untold stories together on one platform.

## 🚀 Features

- **Explore:** Discover India's cultural heritage and landmarks.
- **Stories:** Explore historical accounts, manuscripts and forgotten stories.
- **India Map:** A planned geographical heritage exploration experience.
- **Contribute:** Share photographs, memories and historical knowledge.
- **Community Review:** Help review and improve archive contributions.
- **User Authentication:** Login and signup interface.

## 🛠️ Tech Stack

- React.js
- Vite
- React Router
- Lucide React
- CSS

## 💻 Run Locally

1. Clone the repository.
2. Navigate to the Frontend folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
